# Golden Gate MM - တရားဝင် ကြေးနန်းစာ (Official Telegram) သီးသန့်စနစ် အကောင်အထည်ဖော်ခြင်း အစီအစဉ်

ပေးပို့ထားသော နမူနာပုံစံ (**IMG_7026**) အတိုင်း မြန်မာ့အုပ်ချုပ်ရေးနှင့် လူဝင်မှုကြီးကြပ်ရေးဆိုင်ရာ **တရားဝင် ကြေးနန်းစာ (Official Telegram Format)** ကို သီးသန့် စနစ်တကျ ရေးဆွဲထုတ်ယူနိုင်မည့် ပြည့်စုံသော အစီအစဉ် ဖြစ်ပါသည်။

## User Review & Critical Decisions

> [!IMPORTANT]
> **အသုံးပြုသူ ညွှန်ကြားချက်အရ ပြင်ဆင်သတ်မှတ်ထားသော အချက်များ**:
> 1. **တံဆိပ်တုံးနေရာ လွတ်ထားရှိခြင်း (Blank Seal Area for Physical Stamping)**:
>    - အပေါ်ဘက် အလယ်ဗဟိုနေရာတွင် မည်သည့် တံဆိပ်တုံး/ပုံ အတုအယောင်မျှ မထည့်ဘဲ စာရွက်ထုတ်ပြီးမှ လက်တွေ့ ရုံးတံဆိပ်တုံး အမှန်တကယ် ထုနှိပ်နိုင်ရန် **သန့်ရှင်းသော နေရာလွတ် (Reserved Blank Area)** အဖြစ်သာ ချန်ထားပေးမည်။
> 2. **ထိပ်စီး လက်ခံသူလမ်းကြောင်း (Top Left Routing)**:
>    - `(ပ)`, `(လ)`, `(တ)` စသည့် အတိုကောက် သင်္ကေတများဖြင့် လက်ခံမည့် ဌာနများ ဖော်ပြခြင်း (ဥပမာ- `(ပ) ခရမ၊ လဝပ၊ မူဆယ်`၊ `(လ) ဒုပနမ၊ လဝပ၊ ရှမ်းမြောက်`)။
>    - ကြေးနန်းစာအမှတ် (ဥပမာ- `၀၀၆ / အခမ ၊ ၊`)။
> 3. **ရက်စွဲ/အချိန် (Top Right Date-Time Group / DTG)**:
>    - ညာဘက်အပေါ်တွင် `ရက်စွဲ/အချိန်` ခေါင်းစီးနှင့် အချိန် (ဥပမာ- `၂၀၂၆ ဇန် ၂၂ ၁၆၀၀`)။
> 4. **ကြေးနန်း စာကိုယ်ပိုဒ်များ (Telegraphic Body Structure)**:
>    - `(၁)`, `(၂)`, `(၃)`, `(၄)`, `(၅)` စသည့် နံပါတ်စဉ်များဖြင့် ရေးသားခြင်း။
>    - စာပိုဒ်အတွင်း အဖွဲ့ဝင်/အရာထမ်း စာရင်း (က၊ ခ၊ ဂ၊ ဃ၊ င) ထည့်သွင်းနိုင်ခြင်း။
>    - စာပိုဒ်အဆုံးတွင် ကြေးနန်းသုံး အဆုံးသတ် သင်္ကေတ (`အကကသည်---/` သို့မဟုတ် `အကြောင်းကြားပါသည်---/`)။
> 5. **အောက်ခြေ မျဉ်းတန်းနှင့် လက်မှတ် (Footer Dividing Line & Sign-off)**:
>    - မျဉ်းပြတ်တန်း (`----------------------------------------`) ဖြင့် ပိုင်းခြားခြင်း။
>    - ဘယ်ဘက်: ပေးပို့သည့်နည်းလမ်း (`သင့်ရာနည်းဖြင့်`)၊ လက်မှတ်နေရာ၊ ရာထူးနှင့် အမည် (ဥပမာ- `ခရိုင်ဦးစီးမှူး`၊ `(ထွန်းဇော်ဦး၊ ဒုတိယညွှန်ကြားရေးမှူး)`)။
>    - ညာဘက်: လုံခြုံမှုနှင့် ဦးစားပေး အဆင့်အတန်း (ဥပမာ- `အဆင့်အတန်း`၊ `လျှို့ဝှက် / အမြန်`)။
> 6. **အလိုအလျောက် မူကြမ်းသိမ်းဆည်းမှု (Auto-Save)**:
>    - စာရိုက်နေစဉ် စာသားများ မပျောက်ပျက်စေရန် Local Storage တွင် အလိုအလျောက် Autosave စနစ် ပါဝင်မည်။

## ၁။ စနစ်သုံးသပ်ချက်နှင့် အကျိုးကျေးဇူး (Overview & Core Concept)

* **ဘာကြောင့် သီးခြားခွဲထုတ်ရသနည်း**:
  - ရုံးစာ (အပေါ်စာ) သည် `သို့`၊ `အကြောင်းအရာ`၊ `ရည်ညွှန်းချက်` စသည်တို့ဖြင့် တည်ဆောက်ထားပြီး ကြေးနန်းစာမှာမူ `(ပ)/(လ)/(တ) Routing`၊ `DTG ရက်စွဲ/အချိန်`၊ အလယ်တံဆိပ်တုံးထုရန် နေရာလွတ်၊ `သင့်ရာနည်းဖြင့်`၊ `အဆင့်အတန်း` တို့ဖြင့် တည်ဆောက်ထားသောကြောင့် ပုံစံ လုံးဝ မတူညီပါ။
  - သီးသန့် Tab သို့မဟုတ် Segmented Selector ဖြင့် ခွဲထုတ်ပေးခြင်းဖြင့် ရုံးအရာရှိများသည် လိုအပ်သော ကြေးနန်းစာများကို စံနှုန်းတိကျစွာ မိနစ်ပိုင်းအတွင်း ထုတ်ယူနိုင်မည် ဖြစ်ပါသည်။
* **အလိုအလျောက် မူကြမ်းသိမ်းဆည်းမှု (Auto-Save Draft)**:
  - ကြေးနန်းစာရေးသားနေစဉ် တစ်လုံးချင်းစီ ရိုက်ထည့်မှုတိုင်းကို Local Storage တွင် Auto-save ပြုလုပ်ပေးထားမည်ဖြစ်ရာ အင်တာနက်ပြတ်တောက်ခြင်း သို့မဟုတ် ဖုန်းပိတ်သွားခြင်းများ ဖြစ်ပေါ်ခဲ့လျှင်ပင် မူလအတိုင်း ပြန်လည်ရရှိမည် ဖြစ်ပါသည်။

## ၂။ အသုံးပြုသူ အတွေ့အကြုံနှင့် ဒီဇိုင်း (UX & Layout Design)

### က။ ကြေးနန်းစာ ရိုက်ထည့်မှု ဖောင် (Telegram Input Form)
1. **ထိပ်စီး အချက်အလက်များ**:
   - လက်ခံသူများ စာရင်း `(ပ)`၊ `(လ)`၊ `(တ)`... (+ ထပ်တိုးနိုင်သော Dynamic Row စနစ်)
   - ကြေးနန်း စာအမှတ် (ဥပမာ- `၀၀၆ / အခမ ၊ ၊`)
   - ရက်စွဲနှင့် အချိန် (DTG - ဥပမာ- `၂၀၂၆ ဇန် ၂၂ ၁၆၀၀`)
   - စာပေးပို့သည့် နည်းလမ်း (ဥပမာ- `သင့်ရာနည်းဖြင့်`၊ `Viber ဖြင့်`၊ `ကြေးနန်းဖြင့်`)
   - အဆင့်အတန်း (ရိုးရိုး / အရေးကြီး / အမြန် / လျှို့ဝှက်)
2. **စာပိုဒ်နှင့် စာရင်းများ**:
   - အပိုဒ်လိုက် ရိုက်ထည့်မှု `(၁)`, `(၂)`, `(၃)`...
   - အရာထမ်း/အမှုထမ်း စာရင်းဇယား (က၊ ခ၊ ဂ...) တွဲဖက်ဖြည့်သွင်းနိုင်မည့် ပုံစံ။
   - အဆုံးသတ်စာသား (ဥပမာ- `တင်ပြသွားရန် အကကသည်---/`)။
3. **လက်မှတ်ထိုးသူ အချက်အလက်**:
   - လက်မှတ်ထိုးသူ ရာထူး၊ အမည်နှင့် ဌာန။

### ခ။ ကြေးနန်းစာ စာရွက်ပုံစံ (A4 Telegram Paper Preview)
- နမူနာဓာတ်ပုံ (**IMG_7026**) ပါ အချိုးအစားအတိုင်း A4 စာရွက်ပေါ်တွင်:
  - ဘယ်ဘက်ထိပ်စီးတွင် Routing List `(ပ)`, `(လ)`, `(တ)` နှင့် စာအမှတ်။
  - **အလယ်ဗဟိုတွင် ရုံးတံဆိပ်တုံး လက်တွေ့ ထုနှိပ်ရန် သန့်ရှင်းသော နေရာလွတ် (Blank Reserved Area)**။
  - ညာဘက်ထိပ်စီးတွင် `ရက်စွဲ/အချိန်` (DTG)။
  - အလယ်ပိုင်းတွင် အပိုဒ်စဉ်အလိုက် စာကိုယ်စာသားများ။
  - အောက်ခြေတွင် မျဉ်းပြတ်တန်း၊ ဘယ်ဘက်တွင် `သင့်ရာနည်းဖြင့်` နှင့် လက်မှတ်ထိုးသူ၊ ညာဘက်တွင် `အဆင့်အတန်း`။
- မိုဘိုင်းစခရင်ပေါ်တွင် အပြည့်အဝ ဖတ်ရှုနိုင်ရန် **Fit View (စခရင်အံကိုက်)** စနစ် ပါဝင်မည်။
- **PDF ဒေါင်းလုဒ်** နှင့် **Viber သို့ တိုက်ရိုက်ပေးပို့ခြင်း** အပြည့်အဝ လုပ်ဆောင်နိုင်မည်။

## ၄။ အကောင်အထည်ဖော်မည့် အဆင့်များ (Implementation Steps)

1. **Telegram Types & Schema (`src/types/index.ts`)**:
   - `TelegramInput` data structure အသစ် ဖန်တီးခြင်း (routingRecipients, telegramNo, dateTimeGroup, paragraphs, personnelList, dispatchMethod, securityLevel, signatory)။
2. **Telegram Form & Paper Preview (`src/components/LetterFormatter.tsx`)**:
   - ရုံးစာ (အပေါ်စာ) နှင့် ကြေးနန်းစာ ကူးပြောင်းနိုင်သော Tab Switcher တပ်ဆင်ခြင်း။
   - IMG_7026 နမူနာအတိုင်း တိကျသော ကြေးနန်းစာ စာရွက် visual layout တည်ဆောက်ခြင်း (တံဆိပ်တုံးနေရာကို အလွတ်ချန်ထားမည်)။
3. **Auto-Save Engine Integration**:
   - စာရိုက်နေစဉ် မူကြမ်းများကို သီးခြားစီ Auto-save ပြုလုပ်ပေးသည့် logic ထည့်သွင်းခြင်း။
4. **Verification & Testing**:
   - `compile_applet` နှင့် `lint_applet` စစ်ဆေးခြင်း၊ မိုဘိုင်းနှင့် Desktop view တွင် စာသားများ ညီညာမှုနှင့် PDF/Viber export စစ်ဆေးခြင်း။
